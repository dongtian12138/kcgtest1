# 视觉抓取链修正与抗扰结果

日期：2026-09-04  
范围：simulation-only；50 mm / 15°掌心视觉交接；70°掌面布局；螺母后部 −19 mm；4.5 倍三指等夹力。  
不包含：抓后主键观察、插座精对准、插入、锁紧和真实硬件验证。

GitHub 快照说明：本分支包含本报告、两张关键结果图、当前代码/配置和本轮运行所需的几何资产；每个条件约 160–198 MB 的逐帧物理评价、力传感器序列和仿真真值序列仍保留在本机实验目录中，没有直接提交到 Git。所以下文的“原始证据”路径是本机完整实验证据的位置，远端仓库提供的是可审阅的汇总结果，不等于上传了全部原始时序数据。

## 1. 实际完成的物理结果

修正后的完整链路已经在同一次仿真运行中完成：

`全局 RGB-D → SAM 掩码与浮点深度五自由度粗定位 → Tesseract 到掌心交接位 → 静止采 5 帧 → 冻结掌心位置/轴线 → Tesseract 到预抓位 → 三指独立接触 → 双向力矩调节 → 抬升 → 保持`

名义抓取结果：

- 三指只接触联接螺母，没有接触插头本体；
- 插头实际抬升 `55.976 mm`，保持 `2 s`；
- 最大手指关节力矩 `0.339 N·m`，未触发 `0.900 N·m` 上限；
- 掌心冻结定位误差 `0.488 mm / 0.0286°`；
- 抓取承载阶段插头相对手最大平移 `0.0865 mm`，轴线最大变化 `0.288°`；
- 没有桌面、支架或插头本体非法接触，没有安全停止。

原始证据：`nominal_run1/runtime_result.json` 和 `nominal_run1/physical_grasp_evaluation.json`。

零扰动基线也通过：3.4 s 观察窗口内最大平移 `0.000154 mm`、轴线变化 `0.000186°`；三指累计切向滑移分别为 `0.0329 / 0.0413 / 0.0270 mm`。

## 2. 修掉的会改变结论的错误

1. 插座显示资产曾按错误单位/比例载入，造成右侧巨大插座并穿入桌面。现在使用约 `46.025 mm` 宽的米制 USD，并要求显示包围盒、碰撞几何和安装背面一致。
2. 掌心几何定位曾使用毫米整数深度，量化误差会改变端面轴线。现在 SAM-6D 仍读取其所需的毫米图，而用于位置/轴线计算的是原始浮点米深度。
3. 评价代码曾根据仿真真值把估计轴线翻到“看起来正确”的方向，掩盖真实 180°错误。该翻转已删除。
4. SAM-6D CAD 点采样和 CUDA 推理未完全固定随机源，导致相同输入偶发约 `28.8 mm / 166.8°`跳变。现在固定采样和随机源，并在运动前用独立的掩码/深度几何结果交叉检查；不一致时拒绝规划。
5. 旧报告把“手掌执行到位误差”写成“视觉估计误差”。现在分开记录视觉冻结误差、最终静止重观误差和机械手目标执行误差。
6. 扰动方向曾随插头本体的绕轴转动而变化，使正负横向实验并非固定相对于手指布局。现在方向在每次扰动开始时由抓稳后的手坐标系冻结。
7. 抓取和抬升阶段使用双向力矩调节，而旧扰动阶段只有“力小就继续收紧”，没有“力大就放松”。现在三个阶段使用同一类双向调节：每根手指按力矩误差独立收紧或放松，同时受原行程和力矩上限约束。
8. 旧抗扰通过条件只要求手指仍碰到某个插头零件，可能把碰到插头本体也算通过。现在必须全过程只接触螺母；`−Y 3 倍`失稳时出现本体接触，已被明确判为失败。
9. 螺母—本体转角曾从整次抓取开始累计，混入闭指和抬升过程。现在在外扰开始的零输入帧重新置零，只报告扰动窗口内的相对运动。
10. 活动抓法配置仍残留 `0.31 kg` 的旧工程说明。现已改为 `0.062459669349 kg`；仿真读回本体 `0.0275486 kg`、螺母 `0.0349111 kg`。
11. 位置/轴线是本阶段主指标，但旧评价完整性仍依赖不可见主键角。现在位置/轴线测量完整性与主键测量完整性分开。
12. 物理失败过去可能仍以成功退出码结束。现在：实际通过返回 0，预期物理失败返回 2，运行错误返回 1。

早先采用单向扰动力矩维持控制得到的抗扰数值全部作废；本报告只使用 `final_control_v2` 下重新运行的数据。

## 3. 视觉与路径审计

- 23 个有效扰动条件均重新执行完整全局相机—掌心相机—抓取链，而不是复用一次抓取。
- 全局粗定位误差范围：`0.818–0.915 mm / 0.1143–0.1154°`。
- 掌心冻结定位误差范围：`0.485–0.581 mm / 0.0276–0.0306°`。
- 23 次 SAM-6D PEM—深度几何一致性检查和已知桌面场景检查全部通过。
- 23 条全局到交接路径、23 条交接到预抓路径均由 Tesseract 检查并实际执行；直接关节路径均已无碰撞，因此没有触发 RRTConnect 搜索。
- 全局到交接路径的最小关节软限位余量为 `0.423 rad`，交接到预抓为 `0.317 rad`。
- 23 次扰动的手坐标变换、质心施力点、PhysX 引擎检查和当前控制/资产身份检查均通过；无运行时异常。

这只能证明本场景中的具体直接路径可行，不能证明 Tesseract/RRTConnect 对所有未知场景都能成功。

## 4. 六个力方向的抗扰边界

主通过条件：全过程三指只接触螺母、无安全停止、最大相对平移不超过 `0.5 mm`、插合轴线最大变化不超过 `0.5°`。

| 方向（抓稳后的手坐标系） | 最后通过点 | 首个失败点 | 首个失败的实际原因 |
|---|---:|---:|---|
| +X | `1.838 N`（3 倍自重） | `2.450 N`（4 倍） | 接触丢失，`1.053 mm / 4.960°` |
| −X | `0.459 N`（0.75 倍） | `0.613 N`（1 倍） | 未掉落，但精度失败，`0.540 mm / 1.454°` |
| +Y | `0.613 N`（1 倍） | `0.919 N`（1.5 倍） | 未掉落，但精度失败，`0.893 mm / 1.912°`；2 倍时掉落 |
| −Y | `1.225 N`（2 倍） | `1.838 N`（3 倍） | 接触丢失、碰本体并触发腕部合力保护 |
| +Z 拔出 | `0.613 N`（1 倍） | `0.919 N`（1.5 倍） | 接触丢失，掉落前最大单指滑移 `2.928 mm` |
| −Z 插入 | `1.225 N`（2 倍） | `1.838 N`（3 倍） | 未掉落，但精度失败，`1.211 mm / 3.529°` |

这些是“最后通过点—首个失败点”区间，不是通过插值得到的精确极限。每个载荷点目前只有一次确定性仿真运行。

`+X` 的 `3.040 N`安全上限运行中，抓持位置/轴线仍较小，但触发腕部合力保护，因此同样不能算通过；由于 `2.450 N` 已更早发生接触丢失，边界采用 3 倍通过、4 倍失败。

## 5. 绕轴力矩结果

正、反向 `0.054069 N·m` 均保持了三指接触、位置和插合轴线：

- 正向：`0.0020 mm / 0.0053°`，最大单指滑移 `0.066 mm`；
- 反向：`0.0026 mm / 0.0063°`，最大单指滑移 `0.066 mm`。

但插头本体相对被手抓住的螺母分别连续旋转约 `−5908° / +5909°`。逐帧最大相对转角约 `20°`，低于 180°，因此展开角没有发生采样混叠。

这说明当前抓法能保持插头中心和轴线，却不能靠抓住可转动螺母保持本体键位。它不影响本轮“抓住并搬运”的主判据，但会直接影响下一阶段的主键观察和插入方案。

## 6. 结论边界与仍未解决的问题

已验证事实：修正后的视觉链能在当前固定仿真场景中完成 70° / −19 mm / 4.5 倍抓取、抬升和保持，并得到上述方向相关的有限抗扰区间。

尚不能声称：

- 这不是多随机种子、摩擦/质量/标定扰动下的统计鲁棒性结果；
- `0.020 N·m`螺母空载阻力仍是缺少公开实测值时的工程假设；
- 真实掌心相机外壳尺寸尚未给出，因此相机实体没有进入碰撞模型；
- 仿真未包含真实电缆对插头本体绕轴运动的约束；
- 尚未观察抓后主键，也未执行插座精对准、插入或锁紧；
- 代码审查和这些直接实验不能证明不存在任何其他隐藏缺陷。
