# J599 接合后支撑与针孔卡阻：短试验排查

2026-09-10。**已消除旧的刚性针孔卡点，但尚未完全复现实物轻松旋拧的过程。** 当前没有仿真运行。没有更换原 CAD、增加插头固定关节或提高旋拧驱动上限。

用户确认实物为 J599/26FJ35PN 与 J599/20FJ35SN；工程 CAD 对应 TE D38999/26FJ35PN 与 D38999/20FJ35SN。这确认了对应规格，不能单凭外形认定厂家内部材料与刚度相同。

## 现在能确认的问题

1. **已接合的当前模型并非完全没有侧向支撑。** 在已有接合起点（深度 10.355 mm）对插头本体施加最高 10 N 侧向力和 0.2 N·m 弯矩，最大倾角 0.01588°，最大偏心 10.980 μm。只有插座固定，没有手和外部姿态约束。这是该起点、该方向和该载荷的证据，不能推广为任意偏斜力或首次旋合任意角度都不动。0.05 N·m 的正反螺母试探未产生明显旋转，尚不能称为复现“螺母很松”。
2. **上次旋拧卡阻发生在内部针孔，而非壳体失去所有支撑。** 源几何中壳体单边间隙约 0.12～0.15 mm，针孔径向余量约 0.09144 mm；插针完全刚性时，允许的微小偏移就可能先触发针孔顶碰。相同指令前缀中，旧模型在约 27.65°、10.938 mm 处停滞，针组—孔壁法向力大小之和最高约 854 N；该量不是净力、厂家载荷或机械手需求。
3. **加入有限针孔接触弹性，可以越过该旧卡点。** 新旧回合前 2.5 秒的位姿以及完整指令前缀完全一致；区别从内部接触出现后产生。候选保留所有原顶点、原质量/惯量、碰撞过滤、摩擦和关节，只改变接触律。
4. 第一个弹性候选把原簧套与新插针材料混合后意外变硬，停在约 39.6°。已修正 PhysX 的材料混合规则：该引擎以负恢复系数表示弹性刚度，两个弹性材料使用 `max` 才会选择较软的原簧套刚度；硬—软接触则继续采用软侧。原簧套的 2184.98 N/m 每接触点刚度没有被重新调低。

## 弹性近似的依据与边界

[TE 的结构材料说明](https://www.te.com/en/products/connectors/circular-connectors/intersection/design-mil-dtl-38999-connectors.html)说明触件为镀金铜合金，保持结构为热塑性塑料；它没有给出本型号的弹性模量或接触刚度。

本次使用源 CAD 的插针半径 0.37211 mm、自由圆柱长度 3.81 mm，以及明确假定的铜合金参考弹性模量 120 GPa，以悬臂针尖小挠度公式 `k = 3Eπr⁴/(4L³)` 得到约 98,017 N/m。该值用于原生接触点的有限弹簧，是初期针孔接触近似；不是完整梁模型，也不是厂家标定。多个接触点会并联，轴向端面也受该接触律影响，因此不能据此确认深插、止挡、真实应力或实物受力安全。

修复源码：[prepare_te_pin_entry_compliance.py](../src/kcg_connector/isaac/prepare_te_pin_entry_compliance.py)。加载候选仍使用现有 `install_model.py`；原模型未覆盖。

候选模型：`artifacts/kcg_connector/engagement_support_20260910/pin_entry_compliance_preserved_clips/connector_model.usdc`。它保留作后续局部修复基础，**尚未提升为完整装配已验证的正式基线**。

## 剩余的实际阻塞

最终指令为 47.07875°，实际约 43.60°，末段仍有停滞，驱动弹簧项估算触及保留的 1.6 N·m 上限。这不是已测得的实物旋拧需求。

到 3.653 s 时，128 个簧套已经接触；原生报告出现 3287 个法向接触点，法向力大小之和约 118 N，法向与摩擦合计的轴向分量约 82.7 N。此时针尖对未变形直孔的名义余量已经恢复为正，剩余阻塞不再是原先那几组刚性针孔卡点。需要继续依据已保存数据核对簧套总载荷、接触点数量和摩擦，而不能再次笼统归因于手没扶正，或任意降低刚度、增力来制造成功。

本轮短试验：导向侧推 30.49 s；针孔弹性候选 144.48 s；修正材料混合后 147.18 s。共 322.15 s。另一次启动因缺少 USD 父节点在物理初始化前失败，用时 7.26 s；原因已修复，原记录保留。所有启动均设 175 s 超时及 2 s 强制停止后备，没有长实验、延时、参数盲扫或机器人新回合。
