# 第一版视觉全链路装配：主线与执行计划

核验：2026-09-12。本文已获用户批准执行，允许根据直接证据修订顺序与细节。执行状态见CURRENT_CONTEXT_CN.md；本文不是全链路已经通过的声明。

## 1. 唯一验收目标

**本回合视觉识别桌面插头 → 原三指手用指甲抓本体并离桌 → 视觉识别本体键位与插座键槽 → 搬运、复核并对键插入 → 确认插座自然支承本体 → 真实换抓螺母 → 机械臂旋拧及必要换抓 → 到位后松手，装配保持。**

第一版允许沿用现有桌面、固定插座、相机布置和已知TE料号；不要求先完成随机场景、抗扰统计或硬件迁移。但运动目标必须来自本回合的实际RGB-D及机器人信号，不能直接取场景中的真实物体位姿，不能把事先已插入的初态或多个成功片段拼成验收。

第一版成功至少同时满足：

- 视觉结果确实用于生成抓取和对准动作；保留本回合原始RGB、浮点深度、相机参数、估计结果和消费记录。
- 起始是指甲抓本体。实际离桌、稳定保持与后续搬运均发生；不能只凭末节有接触就认定指甲在承载。
- 本体键实际进入对应槽；不是画面上大致同轴，也不是提前靠插针强行定位。
- 由原机器人真实换抓、旋拧产生推进；无外部转台、隐藏固定、磁吸、物体位姿回写或运行中更换物理模型。
- 本体到原CAD止挡约14.605mm，并符合现有簧套接触、红带遮挡等联合机械判据；不以命令累计360°或退出码代替。
- 最终手完全脱离并保持装配。计划采用2秒有限观察窗口；这是第一版检查窗口，不冒称厂家指标。
- 同一个物理回合保存连续阶段记录和同回合影像。完整验收在运行结束后独立读取真值，在线控制与阶段决策只使用可用观测。

**导纳不是独立交付目标。** 控制选择服从抓取、搬运、插入和旋拧的实际需要。默认复用已有的夹紧反馈、有限位置保持、必要的腕部力反馈；不把完整二阶导纳、导纳扰动研究或电路仿真加成前置条件。

## 2. 找到的主线及目前的断点

建议保留 `run_body_assembly_with_video.py` 作为正式执行包装，接通 `carts_v2/run_grasp_lift.py` 中现有视觉抓取与装配分支；不另起一套大型运行框架。

```text
同一场景初始化：原臂/原指甲手＋新连接器＋相机
  → 本回合RGB-D定位
  → 视觉引导指甲抓Body
  → 抓后键位观察
  → 搬运与到达后的重新观察
  → 插座口部/五键槽定位、对键入槽
  → 支承确认、松开Body、掌面主动换位（如需要）
  → 新图像引导PAD抓Nut
  → 首段旋拧、分段换抓、继续旋合
  → 到位判定、松手、独立后评估
```

现有模块可复用，但以下问题是已查到的事实：

1. `vision-grasp-servo` 分支在视觉抓取后返回结果，未继续调用后面的本体观察/装配链。`grasp-lift` 分支能进入后续装配，但其名义抓取结果不能自动算作“本回合视觉引导抓取”。
2. 新四杆、自锁和电机PD只在 `diagnose_saved_hand_wrench.py` 接通。共同步进器 `JointSignalStepper` 仍直接发送旧式手指位置目标；全链尚未共享新机构。
3. 本体抓位种子是70°掌面布局，新螺母抓位证据是60°。局部脚本用零宽限位固定掌面启动角，不能作为全过程的主动掌面传动。
4. 旧本体配置明写“不限制指腹、指甲或抓取位置”。旧抬升成功证明了抓住Body，不足以证明符合此次指定的指甲承载要求。
5. 已找到的视觉闭环抓取 `physical_rx180_run12…19` 均未离桌，并在腕力矩保护停止。不能把它们列为视觉抓取已通过。此处也不据此判断新模型或真实硬件不可行。
6. 当前局部入口要从旧 `truth_samples.jsonl`、传感器样本恢复初态；旋拧控制器还从9月7日结果文件读取设置。这些是必须解除的运行依赖，不是可凭日期清理的垃圾。
7. 局部诊断还用真实连接器位置作越界中止。该护栏未帮助最近回合产生动作成功，但不能原样带入严格视觉全链的在线决策；应改用可用信号，真值留在独立评价侧。

因此，当前是**已有可复用部件与局部证据，尚无接通后的新版视觉全流程版本**。

## 4. 执行顺序与每一步的通过条件

### 第0步：固定可复现工作版本，停止制造版本混淆

工作：保存当前工作区状态；区分本次有关修改、历史未提交资产和无关更改。将已审阅的模型/执行器、视觉衔接、配置与评价分别提交；不对整个工作区直接 `git add`，不清理用户已有修改。建立一个版本清单，绑定代码提交、完整USD依赖、视觉模板/模型、配置、环境和随机种子。把仍被运行代码读取的历史设置提取成有来源的正式配置。

同时为新回合采用“元数据＋分块原始流＋图像/视频”的记录方式，默认关闭重复巨大 `trace.json` 导出。现有入口已经具备部分分离能力，应补齐压缩和读取支持，不另造日志平台。

通过条件：能说明这版究竟调用哪些文件，并从清单复现现有小基准；未提交代码、历史参数和大型资产不再成为隐蔽依赖。这一步不要求先整理完555GiB历史数据。

### 第1步：把同一套手和连接器接入正式运行时

工作：把四杆位置/速度/Jacobian、每物理步约束更新、电机位置控制、自锁等效模型和传感器语义接入共同 `JointSignalStepper`，覆盖初始抓取、搬运、插入、换抓和旋拧。第一步初始化后不再重置实际手指/物体状态，不在阶段切换时丢掉电机输入端状态。

处理掌面70°→60°的主动换位：默认保留已有抓位种子，补上一个电机驱动两布局轴、到位可保持的真实运动过程；不得通过运行中直接改关节位置或改锁定角跳过去。若源几何表明统一布局可同时满足两种抓取，也可据证据简化，但不能先假定成立。

分别定义“指甲—Body”和“指腹—Nut”的源面区域与评价规则；保留其余物体的碰撞。核对碰撞表示是否忠实保留实际指甲形状。规划工具在固定手型段使用准确展开的关节姿态/碰撞姿态，不能仍按旧1:1计算。

通过条件：两个抓取阶段使用同一机构身份；开合和掌面主动换位可执行；规划、编码器解释和物理运动相符。用现有局部三指基准作受影响回归，不重跑所有历史单体验证。

### 第2步：本回合视觉定位，指甲抓Body并离桌

工作：在当前普通RGB-D中定位插头，由估计结果生成原指甲抓本体的接近、闭合和抬升动作。复用70°本体抓位作为种子，按真实四杆重算；核实实际承载面是指甲。旧名义位姿只能作为几何抓法，不能替代本次视觉定位。

执行中已发现并解决前置问题：新版连接器在原Cube桌面上会在手靠近前漂移约8 mm；同尺寸、同材质的12三角面桌面对照将全程最大位移降至约0.007 mm，且完整空手接近通过。采用项目已有的同形桌面接触表示，不改变物体初态或锁住物体。

桌面视角不必提前识别被遮住的键；必须明确哪些位姿分量被观测、哪些只是抓位选择，不能把假定绕轴角标成测得键角。抓后再识别键位。若再遇到腕力矩停止，先核对真实接触、阶段切换、零点/重力补偿和运动，再决定局部修正，不直接抬高阈值。

通过条件：由本回合图像生成动作，三根指甲实际抓Body；抬升到已有约50mm检查高度并保持2s，离桌接触消失，无掉落/禁止部位抓取或实际状态回写。接触真值只在独立评价中核对。失败就停在这一阶段修复。

### 第3步：抓后识别键位，搬运后再识别

工作：抓稳后用当前图像识别本体轴线和主键，形成当回合手—本体关系；全局图像粗定位插座，利用已有Tesseract路径搬到插座前安全间隙。到达后重新识别本体，并从已有侧方腕观位置识别插座五键槽。

必要性：旧搬运曾使记忆误差达到约1.2mm/6.3°；“一直有夹力”不能证明本体没有在指间迁移。保留重新观察，不能为了省步骤使用固定旧抓内关系。图像看不清时先停稳换可达观察位，不用真值补姿态。

通过条件：本体主键和插座槽角都来自当前可见几何；观察结果、相机外参和机器人坐标一致，足够满足下一步真实配合余量。未解决观测不确定性，不靠加插入力继续。

### 第4步：视觉对键、低速插入，验证自然支承

工作：用最新本体键/插座槽估计做有界对准，在当前连接器模型上低速入槽，使用腕部信号限制受力和判断受阻。到达足以由插座自然约束本体的位置后，逐渐卸载握力，观察是否退出或偏斜。

通过条件：五键实际进入对应槽、没有靠插针错位顶入；没有手—插座异常碰撞、穿透或隐藏支承。卸载后本体仍可由插座自然保持，才允许完全松开本体。旧模型的支承深度不是新版自动通过的依据。

### 第5步：真实换抓Nut，先检查末段间隙

工作：松开Body后按实际机构完成掌面换位和手的避让；用本回合新图像定位螺母，按新60°抓位用原指腹重新夹住。控制不再使用松手前固定的手—Body关系。

在旋拧前先用原CAD及当前受载手型核对从入口到止挡的间隙，重点检查旧回合第三指碰插座、第二指松手回碰的位置；仅检查首次夹住是不够的。必要调整应局限于原几何内的抓位或换抓路径，每次有明确可归因差别。

通过条件：换抓全过程本体不退出键槽；三指确实抓Nut，无Body或插座帮手提供未允许的夹持；具备继续旋拧和最终张开的几何空间。

### 第6步：首段旋拧，再扩展到必要的分段换抓

工作：先做20–40°短段，比较实际螺母转动、轴向推进、夹内滑移和腕部受力。实际带动后再延长到腕部可达的单段，复用已有分段转动—开指—回腕—重新观察—重夹流程。默认从已有90°分段经验出发，按实际可达性决定，不强行只按编号或圈数推进。

最大未知是有限驱动下能否传递深插阶段所需扭矩，以及到位时是否干涉。静态夹住不能证明能旋紧。如果腕转而螺母不转，先区分滑移、抓位、力矩能力与错误碰撞；不直接增加电机上限，不降低连接器阻力制造成功。

通过条件：每段都有实际相对转动及符合机械关系的推进；本体未退出/错键；换抓后可继续，不靠非允许接触帮忙。局部预插入诊断可用来定位失败，但只作调试，不计视觉全链通过。

### 第7步：到位、主动松手、保持

工作：使用可测腕力矩、编码器与可用视觉判断到位趋势和停止；不能在线读取仿真止挡标签或真值深度决定成功。按有间隙的路径张开并撤离，保持观察。运行结束后独立核对原止挡、轴向位置、簧套接触与红带等机械结果。

通过条件：实际达到当前连接器的完整装配状态；最终手部接触消失，观察窗口内装配保持，没有旧回合的碰插座/松手回碰。命令执行完、力矩升高或红带暂时被手遮住都不是充分条件。

### 第8步：从最初视觉开始，取得并冻结第一次完整成功

工作：在同一新回合中连接全部阶段，从未抓起的插头开始，不能载入已插入快照、跨回合接力或拼接成功片段。阶段通过后继续同一个状态；遇到失败保留完整前缀，在最近明确失败处修复，再进行完整执行。

通过条件：满足第1节全部验收条件，即第一版真正成功。若此前某回合已完整满足，直接按其内容验收，不为完成清单额外重复。之后冻结代码提交、配置、资产清单、原始数据、同回合视频和独立评价；“首次成功”与“统计可靠性”分开报告。
