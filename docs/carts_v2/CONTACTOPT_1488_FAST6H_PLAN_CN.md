# CONTACTOPT-1488 当前方法与恢复边界

## 目标

使用同一无指甲三指手、同一方法和主要参数，为两个登记连接器寻找完整六维抓法。候选必须
先有逐指安全接触区间、桌面余量、任务承载能力和可达性，再进入 Isaac 验证真实三指接触、
离桌、抬升至少 50 mm 并保持至少 2 s。

`hardware_authorized=false`、`formal_dynamic_pass=false`。研究动态不能改写正式门。

## 固定方法

1. 严格生成 1488 个三点—材料绑定法向的结构化规格：全局 1040，加密对向组 448。
2. 全量只用缓存 FK、代表点和对象近邻结构做便宜评价，再按固定层级
   `1488 → 120 → 48 → 12 → 3` 收缩。
3. 每指保留 `q_expected` 和 `q_safe_max`；前级只是代理，Top12 才使用原始无指甲
   网格与 Isaac 复合凸双几何。
4. 任务评价保持 12 N 仿真操作上限、登记误差场景和有界 IK/路径检查。
5. 在线控制只使用关节侧可测信号；对象位姿、接触名称、精确接触点和法向只供事后评价。

方法入口配置：`src/kcg_connector/config/carts_contactopt_1488_fast6h.yaml`。
