# CARTS-Grasp V2 北极星

## 总目标

在仿真研究范围内，使用与真实连接器任务一致的无指甲三指手，为两个 D38999/J599 连接器自动寻找完整六维抓法。每个候选先证明完整接近与逐指闭合的桌面安全高度和三指可接触高度存在交集，再按任务承载与误差鲁棒性选 Top-3，最后在 Isaac Sim 中真实推进物理时间完成三指有效接触、离桌、抬升至少 50 mm、保持至少 2 s。两个对象必须使用同一算法和同一组主要参数。

## 真实任务手型与接触语义

- 生产手型是 `CONNECTOR_GRASP_NO_NAIL`：三块用户确认可拆卸的工具指甲必须从可见网格、碰撞网格、质量、质心和惯量中可追溯移除；原带指甲模型只读保留。
- 有效接触语义是 `TASK_GRIP_SURFACE`：允许无指甲手指上面向三指工作空间、闭合时能压向连接器的连通内侧抓持表面。
- 外侧、背面、关节壳体、拆卸安装切面、尖锐非抓持边缘和原指甲均不能作为有效接触；旧蓝色 PAD 保留并单独统计，但不再是唯一允许区域。
- 接触判断使用完整对象三角网格与真实局部表面法向；可运动兼容的允许面为空必须失败关闭，禁止 `argmin(inf)` 选择第 0 点。

## 物理成功条件

- 三根手指均由 `TASK_GRIP_SURFACE` 接触允许连接器表面；非允许部位不能先接触或冒充抓持。
- 抓取能承受重力、登记的抬升加速度和研究扰动；单指、关节与腕部负担处于有来源的研究操作范围。
- 接近、逐指闭合、预紧和抬升过程不允许磁吸、隐藏固定、物体位姿写入或未授权穿透。
- 在线控制只用关节位置、位置误差、关节速度、等效力矩/受力和时间；对象位姿、接触名称、精确接触点/法向和 PhysX 真值只供运行后评价。
- 动态判据同时检查物理时间、真实三指接触、离桌、50 mm 抬升、2 s 保持、滑移、姿态变化、桌面接触和穿透。

## 固定算法顺序

真实对象与无指甲手模型 → 91 个完整掌面构型角与六维种子 → 27 种对象无关三指预构型 → 完整相对路径的有限桌面最低安全高度 `H_table` → 三指可接触高度区间 `H_contact` → 求交集并投影 → 重新计算接触点、停止角、完整闭合和碰撞 → 每角最多 Top-8 → 12 N 任务载荷与误差场景评价 → bounded IK 和全机械臂路径 → 固定字典序 Top-3 → Isaac 研究动态 → 独立事后评价。

高度交集必须在每角 Top-8 之前；禁止先选低位候选再发现扫桌。投影后禁止平移复用旧接触点。27 种预构型可先做对象无关乐观筛选，但每个六维种子最多两种进入精确高度验证，未评估项只能记为预算未评估，不能写成物理失败。

掌面构型主动关节 `f1j1` 在真实合法闭区间 `[0,1.57] rad` 上取 91 个固定等距点；预闭合相位固定为 `{0.00,0.10,0.20}^3`。旧 A/B 各 5824 条 GraspGenX 提案只有在无指甲描述器框架和工作尺度未变时才能作为六维种子复用，旧通过/失败状态全部作废。只有确定性链无候选时，才启用预登记的最多 64 种子/对象、300 次几何评价/种子的有界精修。

最终字典序依次为：名义任务可行；最差误差场景余量最大；较差 20% 场景平均余量最大；最大单指法向力最小；三指负担更均衡；最大关节/腕部利用率更小；完整路径最小安全距离更大；误差敏感性更小；GraspGenX 置信度更高；候选 ID 确定性打破并列。禁止把不同单位指标加权成一个总分。

## 研究问题与方法边界

研究问题：无指甲任务手型、完整六维/掌面构型搜索与 Top-K 前高度投影，能否用同一方法和主要参数，在两个连接器上找到桌面安全、三指可接触、任务可承载并能在 Isaac 中抬升保持的抓法？方法暂称 `NF-HPGS`，不能在没有对照和动态数据前声称创新已验证。

保留三项高信息量对照：带指甲 vs 无指甲；仅旧蓝色 PAD vs `TASK_GRIP_SURFACE`；先选候选后查高度 vs 高度可行域位于 Top-K 前。旧结果只作为消融，不得代表新任务。

## 永久禁止与证据边界

- `hardware_authorized=false` 始终保持；本轮不做真实硬件验证。
- `12 N` 是仿真研究操作上限，不是真实硬件硬极限；旧 `8 N` 只作对照，禁止扫描 8～15 N。
- 旧正式证据线保持失败关闭；研究动态不得篡改它。`formal_dynamic_pass=false`，除非正式合同独立完整闭环。
- 禁止对象专用抓取坐标/阈值、圆柱代理、根据对象 B 结果回调参数、修改桌面或对象姿态来跑通。
- 禁止扩张 H102、建立新连续碰撞证明器或 manager/contract/ledger/bridge/binder/certificate 系统。
- 退出码、静态测试、离线文件、候选数量或视频均不单独等于物理抓取成功。
