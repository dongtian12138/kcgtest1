# CARTS-Grasp V2 北极星

## 总目标

在仿真研究范围内，为 D38999/J599 类活动连接器从真实允许抓取表面自动生成三指抓取候选，按任务承载与误差鲁棒性选择 Top-3，并在 Isaac Sim 中真实推进物理时间完成三指有效接触、离桌、抬升至少 50 mm、保持至少 2 s。开发对象与第二对象必须使用同一算法和同一组主要超参数。

## 物理成功条件

- 三根手指都由真实指腹或内侧有效接触面接触允许表面；指甲、连杆侧面和禁抓面不算有效接触。
- 抓取能承受重力、登记的抬升加速度及预登记小扰动；单指、关节与腕部负担处于有来源的研究操作范围。
- 接近、逐指闭合、抬升过程不允许磁吸、隐藏固定、物体位姿写入或未授权穿透。
- 在线控制只用关节位置、位置误差、关节等效力矩/受力等现实可获得信号；对象位姿、接触名称、精确接触点/法向和 PhysX 真值只供运行后评价。
- 动态判据同时检查物理时间、离桌、50 mm 抬升、2 s 保持、滑移、姿态变化、桌面接触和穿透。

## 固定算法顺序

真实对象与手模型 → GraspGenX 完整六维提案与固定三指手预构型库 → 快速硬约束筛选 → 逐指首次有效接触即停预测 → 任务载荷与误差场景评价 → 固定字典序 Top-3 → Top-3 严格路径碰撞 → Isaac 研究型动态 → 独立事后评价。

本轮生产生成器使用官方预训练 GraspGenX，从多个真实手指预构型给出手掌完整六维位姿。旧轴对称 384 种子生成器保留为消融基线；它无解只否定窄搜索族，不证明三指手无法抓取。GraspGenX 置信度仅作物理可行性之后的后置排序信息。

字典序依次为：最差任务载荷余量最大、较差场景平均余量最大、最大单指法向力最小、最大关节/腕部利用率最小、路径最小安全距离最大、误差敏感性最小、候选 ID 确定性打破并列。禁止把不同单位指标加权成一个总分。

## 研究问题与假设

研究问题：真实 CAD 表面、顺序接触即停预测和任务载荷鲁棒评价，能否用同一算法和主要参数，在两个连接器上选出比几何代理更稳定、且可在 Isaac 中完成抬升保持的抓取？

- `P1_TASK_QUALITY`：任务承载排序优于几何代理排序。
- `P2_SEQUENTIAL_CONTACT`：逐指接触即停比三指同步硬闭合更少推走物体。
- `P3_UNCERTAINTY`：预先考虑接触、位姿、摩擦等误差的候选在扰动下更稳定。
- `P4_TWO_STAGE`：先快筛/力学排序、再验证 Top-3，可显著减少规划时间而不降低动态成功。

## 永久禁止与证据边界

- `hardware_authorized=false` 始终保持；本轮不做真实硬件验证。
- 本轮主配置的 `12 N` 是仿真研究操作上限，不是真实硬件硬极限；旧 `8 N` 结果保留为消融基线，禁止在 8～15 N 间扫描。
- 旧正式证据线保持 `dynamic_launch_allowed=false`、`selected_candidate=null` 和 `NOT_CERTIFIABLE`，除非其原合同独立闭环；V2 研究动态不得篡改它。
- 研究成功只称 `RESEARCH_DYNAMIC_PASS`；满足完整路径证据、双对象同参数、多次独立运行、预登记扰动和统计后才可能称 `FORMAL_DYNAMIC_PASS`。
- 禁止对象专用抓取坐标、固定候选编号、对象专用阈值、圆柱替代真实外形、根据第二对象结果回调主要参数。
- 禁止继续扩张旧 H102 路线；旧巨型碰撞模块只通过一个薄公开适配器服务 Top-3。
- 退出码、静态测试、离线文件或日志中的 `PASS` 均不单独等于物理抓取成功。
