- 假设：默认测试入口同时收集了当前维护测试、已结束任务的字节哈希合同、证据包完整性快照和本机绝对路径合同，因此大量失败不等于当前主线算法回归。

## 版本控制原则

1. 当前代码、当前测试和短入口文档保留在主分支。
2. 已结束任务的可执行历史不再复制为 ZIP 后继续占据主分支；由保护标签和 Git 历史恢复。
3. 外部交付证据仅保留已校验归档及校验文件，不保留重复解压树。
4. 每次提交只暂存本轮清理文件，不混入并行进行的 CARTS、J599 或依赖配置修改。
