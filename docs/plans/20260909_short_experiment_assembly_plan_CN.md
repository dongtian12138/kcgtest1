# 电连接器装配计划：先查已接合约束，再研究三指手旋紧

状态：用户已授权执行。已完成最早偏斜的因果定位和有限短窗修复检查；完整装配尚未成功。所有动态运行均已结束，详细结果见 CURRENT_CONTEXT_CN.md。严格短试验限制继续有效。

## 一、当前第一优先级

用户反复确认的实物行为是：正确旋合几十度后，插头和插座已经相互套牢，轻微施力偏斜不容易将插头顶歪；主要还能运动的是螺母，转动螺母会牵引插头继续推进。

**先查当前仿真是否正确表现这个接合状态。没有解释清楚前，不将提高握力、反复视觉纠偏或扩大控制方案作为主要方向。**

已有记录显示，在最近回合最初约2秒、没有手或其他机器人部件接触连接器时，倾斜约0.058°→0.536°、横向偏移约12.4µm→100.4µm。它足以排除手接触直接造成最早变化，但尚不能单独证明哪项模型定义错误；合法间隙运动、初态不自洽与接触表示问题仍须区分。

“旧回合转过180°”不能自动证明当前模型和初始化已经正确接合。“外夹具保持对准时完整旋合成功”也不能证明解除外部姿态支撑后的中途约束一定合理。

## 二、用户问题与工作对应

| 用户问题 | 必须做的工作 | 必须拿到的答案 |
|---|---|---|
| 已套牢为什么还会歪、卡？ | 核对当前接合几何、约束、初始化及最早接触 | 是否真的处于正确接合状态，哪个因素引起最早异常 |
| 正常还需要多大旋拧力？ | 在合理接合状态下测实际扭矩、转角和推进 | 正常旋合的负载范围，区别于卡阻力和驱动上限 |
| 三指手怎样抓才不滑？ | 依据胶垫、几何和所需扭矩筛抓法 | 可用的掌面角、位姿、接触位置及握持目标 |
| 腕部应该怎样控制？ | 旋转与轴向自然跟进协调 | 不拖住推进、不无依据持续推压的控制方法 |
| 为什么架构和版本一直乱？ | 清理当前主路径、修记录/显示、固定有效配置并提交 | 可使用、可回退、可复现的运行入口 |

物理主线：
**正确接合状态 → 正常扭矩需求 → 抓法和握持 → 腕部旋拧与跟进 → 同回合完整装配。**

工程整理是支撑工作，可以与已有数据分析交错推进；不能再次排成一串长期前置研究。

## 三、第一项工作怎样查：不先开新实验

使用现有最初1920帧、源模型定义和已有单体成功记录：

1. 确定偏移、倾角、螺母角度和轴向位置最早变化的时刻。
2. 核对该起点是否真的具有正确的对键和螺纹接合关系，不能仅凭插入深度或历史角度认定。
3. 检查承担径向导向和抗倾斜的壳体、键槽及螺纹表面是否在物理模型中存在、参与正确碰撞，是否被误过滤或不合理地替换为柔软接触。
4. 检查Body与Nut的被动关节轴线、坐标系和允许自由度是否符合真实结构。
5. 检查从旧回合复制到当前模型的位姿、速度及接触状态是否自洽，是否已有重叠或释放了不合理的初始载荷。
6. 按具体碰撞对查看接触与累计冲量，而不是仅看一个瞬时力峰。
7. 将实际位移与源几何间隙比较。不要求数学上的绝对零倾角，也不把用户手感当定量刚度标定。
8. 明确成功单体试验中外夹具提供了哪些约束，不能将夹具的效果归功于连接器自身。

| 查明的情况 | 对应修复 |
|---|---|
| 初态没有正确接合或与当前模型不兼容 | 修诊断初始化，另行保留全过程验收 |
| 导向/接触/关节表示不合理 | 只修已定位部分，保留真实尺寸、质量和应有自由度 |
| 运动属于合法间隙，程序门槛过严 | 修判据与控制假设，不强逼零偏差 |
| 仍不能区分 | 只设计一次能区分这些解释的短对照 |

禁止额外锁住插头来证明“稳定”。固定插座是正常安装条件，隐藏固定插头是另一回事。

输出必须具体：当前起点能否称为正确接合、最早异常来自哪里、哪一处需要修、哪些解释已排除。没有证据就保留未知，不再口头保证模型完全没问题。

## 四、接合行为合理后，再测正常旋拧需求

测实际螺母转角、轴向推进、扭矩和必要的轴向载荷，区分空行程、正常旋合、接近止挡和到位后过驱。

优先复用已有有效数据。若机械手某段已经正常推进且无明显滑动，该段测力可同时提供载荷依据，不机械地追加一整条夹具曲线。

需要独立夹具时，只用于当前短窗口诊断，不混入机器人成功结果。驱动上限不是实际所需扭矩，卡阻或滑动下的负载也不是正常需求。

首先取得足以指导抓法和控制的范围，不为完整材料标定、最大能力图谱无限推迟装配。

## 五、匹配自研三指手的抓法与握持

已知手指有防滑胶垫，不能依靠宽块边缘顶住传扭；可测关节位置和指根等效关节力矩，没有现成的实物螺母抓持基准。

1. 保留当前抓法作比较，离线筛选掌面角、手掌位姿、绕轴方向和接触高度。
2. 最多提出三个有理由的候选，排除接触Body/插座、够不到螺母、接近关节极限或没有旋拧行程的方案。
3. 优先验证最有依据的候选。能够可靠传递所需扭矩，就进入装配控制，不继续穷举全部候选。
4. 以位置和等效关节力矩建立握持反馈，核对仿真信号定义和实物含义。
5. 不把等效力矩直接当成指腹法向力，不用母线电流代替精确握力，不带载清零。
6. 胶垫具体摩擦、厚度和柔顺参数未知时明确标为假设，不为跑通随意增大摩擦。
7. 旧15N、0.25Nm等值不自动成为自研手额定。按用户要求重新安排试验限值，实际驱动仍须有限、明确、可追溯。

失败先区分接触未形成、部位错误、滑动、关节让动、驱动饱和和轴向被拖住；不能统一解释为“握力不够”。

## 六、腕部控制按真实动作组织

接合前处理对键和对准；接合后以带动螺母转动、允许螺纹牵引推进为主。

- 不锁死前后位置，不无依据持续推压。
- 先核对力信号及重力补偿含义，“不主动推”不等于把所有参考值设成0。
- 若结构已提供正常导向，不默认持续将Body拽回虚拟理想轴。
- 保留必要观测和异常检查，不让反复纠偏取代旋拧。
- 握持等待使用有依据的稳定条件和短上限，不再长时间静等。
- 行程不足时复用原来的张手、回腕和重抓逻辑，释放前确认合理支撑。
- 实际螺母角与接触真值用于事后评价，不偷偷送入控制器。力矩稳定不自动等于没有滑动。

只优化已证明的重复保存、加载、创建资源和采集。World.step可能含附加回调，不能仅凭名称认定全部耗时属于求解器。没有新依据，不重启旧CPU/GPU或迭代数试验。

## 八、短试验限制继续有效，但不另开性能研究

- 局部动态诊断上限3分钟。
- 机器人短拧或完整回合上限5分钟。
- 排障同一问题最多两次，累计不超过10分钟。
- 均按启动到保存结果的墙钟时间计算；不换名、重启、延时或切分续跑规避。

这些数值是本计划的执行限制，不是物理定律。利用现有数据与当前最小物理试验顺便记录速度，不将通用性能认证列成独立研究课题。

预计无法在限时内完成时不启动，先修已定位的具体瓶颈。若在保持真实性的条件下仍做不到，明确报告冲突，不擅自降低物理要求，也不恢复几十分钟试验。
