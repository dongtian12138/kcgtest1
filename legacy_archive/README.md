## 使用边界

1. 当前入口仍是根目录 `README.md` 和 `artifacts/agent_control/` 控制面。
2. 不要直接运行或导入本目录中的源码、测试和脚本；需要恢复时先重新审计。
3. `artifacts/` 中的冻结模型、动态日志和证据没有移动到这里，必须保持原路径。
4. `build/`、`install/`、`log/` 和 `.venv/` 是当前可重建工作环境，不属于本归档。
5. 本目录中的旧文档可能含历史路径或旧状态，只用于追溯。
