# 螺母角度估计修复：局部已验证，完整复验待完成

问题发生在中途重新抓住螺母，使用掌心深度图估计螺母外圈方向。旧方法将原CAD表面随机采样为点云，并最小化到这些点的距离。相机改变视角后，像素采样与离散模板点的相对位置改变，采样空隙形成与实际转动无关的角度代价。此前同一个几乎静止的螺母被估为227.275°和227.800°，触发原0.5°复核门。

修复只将距离改成到原始CAD三角形连续表面的距离，使用现有Warp CPU BVH加速。不修改相机布局、物理模型、质量、材料、求解器、夹持力、5°修正上界或0.5°验收门。不使用运行中的对象/接触真值。独立双精度穷举三角形投影和边距离与BVH在540个查询点上最大差低于2.8纳米。

固定输入重放了原高位失败回合和低位成功回合的16幅图像，原质量门全部通过。旧失败两帧的新估计在0.025°搜索分辨率下均为227.500°，原校正后图像的新误差-0.221842°。所有已有校正后图像的误差均小于原0.5°，但重放不能代替新的物理动作。匹配计算核约0.058秒，旧核约0.095秒；包括深度处理的新方法中位每帧0.106秒。首次内核编译是一次性准备开销，不能把局部匹配耗时当作整机提速。

局部动态复验从封存回合的开放手指状态在reset前初始化，之后只使用本次图像、编码器和力信号。场景是独立故障诊断，不是原全过程续接。local_fourth_grasp_02运行1175.338秒、8503步，完成原重新抓握控制；新图像复核误差-0.021783°，通过原0.5°门；原定源接触区域审查及键槽侧壁几何审查均通过。局部没有执行后续旋紧或最终释放。
